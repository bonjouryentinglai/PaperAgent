# Roadmap

## Native assistant preview

- AI and Beautify actions in the Xochitl lasso menu.
- ChatGPT subscription transport through Pi OAuth.
- Traditional Chinese and Latin handwriting writeback.
- Typed text, table and vector renderers.
- GPT Image generation and guarded native Xochitl image insertion.
- Streaming text and visible request status.
- Transactional developer install and rollback.

Before the preview is called stable, tables, vectors, GPT images and both
Beautify routes must be accepted on a physical Move across several selection
sizes and page positions.

## Productization

- One guided installer for supported firmware versions.
- Browser/device login flow with clear credential storage and revocation.
- Settings UI for provider, model, thinking level, text size and handwriting
  font.
- Compatibility detection before Xochitl is modified.
- Signed release artifacts, checksums, upgrade and uninstall paths.
- Friendly offline, timeout, login-expired and unsupported-firmware messages.

## Complete notebook integration

- Undo-safe Beautify replacement instead of a side-by-side copy.
- Positive Xochitl insertion acknowledgement and compatibility guards for
  generated notebook images.
- Dashed or variable-weight vector strokes, organic smooth-fill curves and
  richer table layout.
- Selection placement choices and multi-page output.
- Optional notebook indexing and cited note search.
